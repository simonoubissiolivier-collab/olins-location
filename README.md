# OLINS Locations Cameroun

Plateforme nationale de location de logements au Cameroun.

## Installation
1. Configurer Firebase dans `js/firebase-config.js`
2. Déployer sur Firebase Hosting ou tout hébergeur statique

## Structure
- `index.html` - Page d'accueil
- `css/style.css` - Styles complets
- `js/modules/` - Modules JavaScript
